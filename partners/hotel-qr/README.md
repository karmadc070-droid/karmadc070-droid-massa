## 추적 기능 현황 — 이미 있음 (2026-10-29 운영 적용)
새 코드는 필요 없다.
- 링크 형식은 `https://app.massaviet.com/?p=<코드>` 이고, 지시에 적힌 `?partner=` 가 아니다. 이미 인쇄된 카드와 앱 링크 처리가 모두 이 형식이라 바꾸지 않는다.
- 앱(웹·네이티브)이 코드를 기기에 30일 보관하고, 로그인되면 `claim_partner` 로 계정을 숙소에 연결한다(`partner_guests`).
- 연결 후 30일 안의 예약은 `partner_bookings` 에 귀속하고, 완료되면 손님 결제액의 `partners.commission_rate`(기본 0.10)를 `pending_payout` 으로 적는다.
- 관리자(/admin) '호텔 · 레지던스 제휴' 카드에서 숙소 추가(코드 자동 6자리), 지급 대기·완료, '지급', '인쇄용 카드', '링크 복사'를 할 수 있다.
- 한계는 지연 딥링크가 없다는 점이다. 앱 설치 전 웹에서 QR을 열면 코드는 웹 저장소에만 남아서, 스토어에서 새로 설치한 앱으로는 넘어가지 않는다. 숙소 손님은 웹(app.massaviet.com)에서 바로 예약하게 안내하는 게 귀속에 유리하다.

## 사용자가 정할 것
1. **수수료율.** 시스템 기본값은 10%(손님 결제액 기준)다. 숙소별로 다르게 하려면 `partners.commission_rate` 를 숙소마다 넣는다.
2. **정산 주기와 방법.** 월 1회 계좌이체 등을 정해야 한다. 관리자 '지급' 버튼은 지급 완료 표시만 한다.
3. **첫 제휴 대상.** `candidates-hanoi.md` 의 1순위(서비스드 아파트·장기 체류형) 중에서 고른다.
4. **제안서의 문의 연락처.** 이메일, 잘로, 전화 중 무엇을 적을지 정한다.
5. **카드 문구 추가 여부.** 첫 이용 혜택처럼 확정된 혜택이 있으면 카드에 한 줄 넣을 수 있다. 지금은 확인된 사실만 적었다.

## 진행 순서 (결정 후)
1. 관리자 화면에서 숙소 추가 → 코드 발급
2. `node render-hotel-card.js <코드> "<숙소명>"` 로 카드 PDF 를 만들어 인쇄(A6, 두꺼운 종이·스탠드)
3. 제안서(숙소 언어)와 카드 샘플을 들고 방문하거나 공식 문의 경로로 연락
4. 비치 후 관리자 카드에서 연결 손님, 예약, 적립을 주 1회 확인
