# App Store 등록정보 보완 (ko-KR 기준)

## 먼저, 앞서 잘못 짚은 것

iTunes 조회 API 의 `languageCodesISO2A: ["EN"]` 을 보고 "스토어 등록정보가 영어뿐"이라고 했는데
**틀렸다.** 그 값은 **앱 번들이 선언한 언어**(Info.plist)지 스토어 등록정보 언어가 아니다.

App Store Connect 에서 직접 확인한 실제 상태 (2026-09-15).

- **기본 언어 = 한국어** — 등록정보는 이미 한국어다. 고칠 게 없다.
- `["EN"]` 은 Capacitor 로 만든 iOS 번들이 영어 하나만 선언해서 나온 값이다.
  앱은 실제로 5개 언어를 쓰는데 제품 페이지 '언어' 칸에는 영어만 뜬다. 따로 고쳐야 한다.

## 실제로 비어 있거나 틀린 것

| 항목 | 현재 | 고칠 값 |
|---|---|---|
| 부제 | **비어 있음** | 베트남 집·호텔로 찾아오는 방문 예약 |
| 마케팅 URL | https://massa-seven.vercel.app | https://massaviet.com |
| 지원 URL | (확인 필요) | https://massaviet.com/contact.html |
| 번들 언어 선언 | en 하나 | ko, vi, en, ja, zh |
| 영어·베트남어 현지화 | 없음 | 추가 |

## 잠금 상태

1.0.6 이 이미 출시돼서 **이름·부제·설명·키워드·URL 이 전부 잠겨 있다.**
고치려면 **새 버전(1.0.7)을 만들어야** 하고, 새 버전에는 새 빌드가 필요하다.

심사 없이 지금 바꿀 수 있는 것은 **프로모션 텍스트 하나뿐**이다. 2026-09-15 에 아래 문구로 넣었다.

2026-11-05 베트남 전역 기준으로 바꿀 문구(콘솔 반영은 사용자 확인 후).

```
베트남 전역 오픈 기념 진행 중. 검증된 테라피스트를 집이나 호텔로 부르고, 서비스가 끝난 뒤 현장에서 결제합니다. 표시 금액에 세금과 팁이 포함돼 나중에 더 붙지 않습니다.
```

## 1.0.7 에 함께 넣을 것

### 부제 (30자)
```
베트남 집·호텔로 찾아오는 방문 예약
```

### 키워드 (100자, 쉼표 구분 · 공백 없이)
이름·부제에 이미 있는 낱말은 넣지 않는다. 자동으로 같이 색인된다.
```
출장,홈케어,홈뷰티,네일,왁싱,아로마,스웨디시,타이,딥티슈,베트남,마사지,스파,후불,한국어,하노이,호치민,다낭,아파트,레지던스
```

### 번들 언어 선언
`capacitor/ios/App/App/Info.plist` 에 `CFBundleLocalizations` 배열로 ko·vi·en·ja·zh 를 넣는다.
이걸 넣어야 제품 페이지 '언어' 칸이 5개로 뜬다.

### 베트남어 현지화
`vi-VN-등록정보.md` 에 카피가 있다. **원어민 검수 전이다.**

### 영어 현지화
아직 카피가 없다. 필요하면 새로 쓴다.
